# 向量 + 关键词混合检索

## 1. 混合检索原理

```
用户查询
   ├─→ 向量检索（语义相似）→ Top-K1 结果（带分数）
   └─→ BM25检索（关键词匹配）→ Top-K2 结果（带分数）
         ↓
    分数融合（RRF / 加权组合）
         ↓
    重排序 → 最终 Top-K 结果
```

## 2. BM25 算法

### 2.1 原理

BM25（Best Matching 25）是经典的信息检索算法，基于词频（TF）和逆文档频率（IDF）。

```
BM25(D, Q) = Σ IDF(qi) × (f(qi, D) × (k1 + 1)) / (f(qi, D) + k1 × (1 - b + b × |D| / avgdl))
```

- `f(qi, D)`：词 qi 在文档 D 中的词频
- `k1`：词频饱和参数（通常 1.2-2.0）
- `b`：文档长度归一化参数（通常 0.75）
- `avgdl`：平均文档长度

### 2.2 Python 实现

```python
# pip install rank-bm25
from rank_bm25 import BM25Okapi
import jieba

class BM25Search:
    def __init__(self, documents: list[str]):
        self.documents = documents
        # 中文需要先分词
        self.tokenized_docs = [list(jieba.cut(doc)) for doc in documents]
        self.bm25 = BM25Okapi(self.tokenized_docs, k1=1.5, b=0.75)

    def search(self, query: str, top_k: int = 10) -> list[dict]:
        tokenized_query = list(jieba.cut(query))
        scores = self.bm25.get_scores(tokenized_query)
        
        # 按分数排序
        scored_indices = sorted(enumerate(scores), key=lambda x: x[1], reverse=True)
        
        results = []
        for idx, score in scored_indices[:top_k]:
            results.append({
                "index": idx,
                "content": self.documents[idx],
                "score": float(score)
            })
        return results

# 使用示例
docs = [
    "楚子航看着他的背影，忽然想也许自己能捎他一程",
    "路明非正在发呆，不知道在想什么",
    "前言部分为首的三行，分别是小说名、序幕章节名",
]
bm25 = BM25Search(docs)
results = bm25.search("楚子航 路明非", top_k=3)
```

## 3. 分数融合方法

### 3.1 Reciprocal Rank Fusion (RRF)

RRF 论文：Cormack et al. (2009), ACM SIGIR

```
RRF_score(d) = Σ 1 / (k + rank_i(d))
```

- `k`：常数，通常取 60
- `rank_i(d)`：文档 d 在第 i 个检索器中的排名

```python
def reciprocal_rank_fusion(
    rankings: list[list[dict]],  # 多个检索器的结果
    k: int = 60
) -> list[dict]:
    """RRF 分数融合"""
    scores = {}  # doc_id -> rrf_score
    
    for ranking in rankings:
        for rank, item in enumerate(ranking, start=1):
            doc_id = item["index"]
            if doc_id not in scores:
                scores[doc_id] = 0.0
            scores[doc_id] += 1.0 / (k + rank)
    
    # 按RRF分数排序
    sorted_items = sorted(scores.items(), key=lambda x: x[1], reverse=True)
    
    return [{"index": doc_id, "rrf_score": score} for doc_id, score in sorted_items]
```

### 3.2 加权线性组合

```python
def weighted_fusion(
    vector_results: list[dict],
    bm25_results: list[dict],
    vector_weight: float = 0.7,
    bm25_weight: float = 0.3,
    top_k: int = 10
) -> list[dict]:
    """加权线性组合融合"""
    scores = {}
    
    # 归一化向量分数到 [0, 1]
    if vector_results:
        max_vec = max(r["score"] for r in vector_results)
        min_vec = min(r["score"] for r in vector_results)
        range_vec = max_vec - min_vec if max_vec != min_vec else 1.0
        
        for item in vector_results:
            doc_id = item["index"]
            normalized = (item["score"] - min_vec) / range_vec
            scores[doc_id] = {"vector": normalized * vector_weight, "bm25": 0.0}
    
    # 归一化BM25分数到 [0, 1]
    if bm25_results:
        max_bm25 = max(r["score"] for r in bm25_results)
        min_bm25 = min(r["score"] for r in bm25_results)
        range_bm25 = max_bm25 - min_bm25 if max_bm25 != min_bm25 else 1.0
        
        for item in bm25_results:
            doc_id = item["index"]
            normalized = (item["score"] - min_bm25) / range_bm25
            if doc_id not in scores:
                scores[doc_id] = {"vector": 0.0, "bm25": 0.0}
            scores[doc_id]["bm25"] = normalized * bm25_weight
    
    # 合并分数
    final = []
    for doc_id, s in scores.items():
        final.append({
            "index": doc_id,
            "final_score": s["vector"] + s["bm25"],
            "vector_score": s["vector"],
            "bm25_score": s["bm25"]
        })
    
    return sorted(final, key=lambda x: x["final_score"], reverse=True)[:top_k]
```

## 4. 完整混合检索实现

```python
class HybridRetriever:
    def __init__(self, documents: list[str], embedding_model, vector_store):
        self.documents = documents
        self.bm25 = BM25Search(documents)
        self.embedding_model = embedding_model
        self.vector_store = vector_store
        self.reranker = None

    def set_reranker(self, reranker):
        self.reranker = reranker

    async def search(self, query: str, top_k: int = 5,
                     fusion_method: str = "rrf") -> list[dict]:
        # Step 1: 向量检索
        query_embedding = await self.embedding_model.aembed_query(query)
        vector_results = self.vector_store.search(query_embedding, top_k=top_k * 4)
        
        # Step 2: BM25检索
        bm25_results = self.bm25.search(query, top_k=top_k * 4)
        
        # Step 3: 分数融合
        if fusion_method == "rrf":
            fused = reciprocal_rank_fusion([vector_results, bm25_results])
        else:
            fused = weighted_fusion(vector_results, bm25_results)
        
        # Step 4: 取候选集
        candidates = []
        for item in fused[:top_k * 2]:
            idx = item["index"]
            candidates.append({
                "content": self.documents[idx],
                "score": item.get("final_score", item.get("rrf_score")),
                "index": idx
            })
        
        # Step 5: 重排序（可选）
        if self.reranker and candidates:
            pairs = [[query, c["content"]] for c in candidates]
            rerank_scores = self.reranker.predict(pairs)
            for i, score in enumerate(rerank_scores):
                candidates[i]["rerank_score"] = float(score)
            candidates.sort(key=lambda x: x["rerank_score"], reverse=True)
        
        return candidates[:top_k]
```

## 5. 性能对比

| 方法 | Recall@5 | Recall@10 | MRR | 说明 |
|------|----------|-----------|-----|------|
| 纯向量检索 | 0.72 | 0.81 | 0.65 | 语义理解好，精确匹配差 |
| 纯BM25 | 0.68 | 0.78 | 0.61 | 精确匹配好，语义理解差 |
| RRF融合 | 0.82 | 0.89 | 0.76 | 两种方法互补 |
| 加权融合 | 0.79 | 0.87 | 0.73 | 需要调权重 |
| RRF + Rerank | 0.87 | 0.93 | 0.82 | 最佳组合 ✅ |

*注：以上数据为一般场景下的典型表现，实际效果取决于数据集和模型选择*
